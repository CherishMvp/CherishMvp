## 关于我

我是一个喜欢 **生活、编程、写作和折腾新工具** 的独立开发者。

我平时会收藏很多开源项目、产品想法和技术实践。  
对我来说，Star 不只是收藏夹，更像是在持续维护一份属于自己的 **技术雷达**。

我喜欢广泛探索，但也希望在合适的时候，把这些积累沉淀成真正可用的工具、文章或产品原型。

---

## 关注方向

- **开发效率与工具链**  
  关注如何借助工具提升编码、思考、写作和产品构建效率。

- **技术收藏与筛选**  
  长期收藏和观察有价值的项目，从中提炼技术趋势、产品思路和实现模式。

- **全栈工程实践**  
  从前端交互、移动端体验，到后端 API、数据服务和产品交付。

- **写作与沉淀**  
  记录技术笔记、生活片段、工具体验和阶段性的思考。
